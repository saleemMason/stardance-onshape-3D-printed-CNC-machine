# stardance-onshape-3D-printed-CNC-machine

This is my submission for the Hackclub stardance challenge. I am designing desktop 3dprinted CNC machine using Onshape.

Be able to fit on my table 
the structural components will be able to be 3d printed. 
I cad all of it first so I know exactly how much stuff I need.
Make it rigid enough to cut aluminum to the tolerance of 0.001
